# ✦ Particle Hero Section

A modern and interactive hero section featuring a smooth particle animation that subtly responds to user cursor movement.

The particle background follows cursor interactions with a controlled delay, creating a smooth, cinematic, and dramatic motion effect instead of an instant mechanical response.

---

## ✨ Overview

**Particle Hero Section** is an interactive hero section designed to create an engaging first impression.

The project combines a clean navigation header with a dynamic particle-based background. As users move their cursor, the particle animation gradually reacts to the movement, creating a smooth and immersive visual experience.

The delayed response between cursor movement and particle motion adds depth and fluidity, making the interaction feel more natural and visually dramatic.

---

## 🚀 Features

- ✨ Interactive particle animation
- 🖱️ Particle movement responds to cursor interaction
- 🌊 Smooth delayed cursor response
- 🎭 Cinematic and dramatic motion effect
- 🧭 Responsive navigation header
- 📱 Responsive layout
- ⚡ Fast development environment powered by Vite
- 🎨 Modern UI styling with Tailwind CSS
- 🧩 Reusable UI components
